🎮 GAME CONTROLS
────────────────────────────────────────────────────────────────────────────

CHARACTER SELECTION SCREEN:
  ← / → (Arrow keys)     Select character left/right
  A / D                  Alternative: Select left/right
  ENTER                  Confirm selection → Start gameplay
  ESC                    Exit game

GAMEPLAY SCREEN:
  W / ↑ (Arrow up)       Move UP
  A / ← (Arrow left)     Move LEFT
  S / ↓ (Arrow down)     Move DOWN
  D / → (Arrow right)    Move RIGHT
  ESC                    Return to character selection

🐛 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

PROBLEM: "Game won't start"
SOLUTION: 
  1. Run TEST_GAME.bat to diagnose
  2. Check Java is installed: java -version
  3. Check bin/ directory exists with .class files
  4. Check Resources/industrial-zone/ directory exists

PROBLEM: "Character sprite not showing"
SOLUTION:
  1. Check: Resources/industrial-zone/characters/player/{name}/
  2. Check: PNG files exist in that directory
  3. Check console output for error messages

PROBLEM: "Level background not showing"
SOLUTION:
  1. Check: Resources/industrial-zone/1 Tiles/Industrial_zone_level_1/
  2. Check: 2 Background_level_1/ subdirectory exists
  3. Check: BG_Composite_*.png file exists

PROBLEM: "Game runs but everything is black"
SOLUTION:
  1. Assets may not load (check Resources directory)
  2. Check console output for load errors
  3. ManifestLoader should print messages showing what loaded
