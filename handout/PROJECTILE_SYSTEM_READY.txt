### Detection Pattern
```
Single-Sprite Indicators:
  - "1Frame" in filename
  - "Single" in filename
  - Very small dimensions (~6-15px)
  
Sprite-Sheet Indicators:
  - "6Frames1Row" or "7Frames1Row" format
  - Medium animation complexity
  - Frame timing in filename (80ms, 100ms, etc)
```

### Trajectory Types Identified
```
1. STRAIGHT (12)    - Direct line paths
2. ARC (2)          - Parabolic throw motion
3. BOOMERANG (2)    - Orb projectiles + return
4. HOMING (1)       - Auto-aim capable
5. INSTANT (1)      - No travel animation
6. CURVED (3)       - Custom curve paths
```

## 🎯 Auto-Aim Algorithm

```
STEP 1: Get Positions
  enemy.x, enemy.y = Current enemy position
  player.x, player.y = Current player position

STEP 2: Calculate Direction Vector
  dx = player.x - enemy.x
  dy = player.y - enemy.y
  distance = sqrt(dx² + dy²)
  
STEP 3: Calculate Aim Angle
  aimAngle = atan2(dy, dx)

STEP 4: Apply Difficulty Spread
  IF difficulty == EASY:
    aimAngle += random(-15 to +15 degrees)
  IF difficulty == NORMAL:
    aimAngle += random(-8 to +8 degrees)
  IF difficulty == HARD:
    aimAngle += random(-3 to +3 degrees)

STEP 5: Launch Projectile
  projectile.velocity.x = cos(aimAngle) * projectile.speed
  projectile.velocity.y = sin(aimAngle) * projectile.speed
  projectile.x = enemy.x + projectile.spawnOffsetX
  projectile.y = enemy.y + projectile.spawnOffsetY
```
