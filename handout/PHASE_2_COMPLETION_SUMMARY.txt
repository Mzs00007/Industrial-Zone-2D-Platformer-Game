
### Keyboard Controls
```
CHARACTER SELECT:
  ← / → or A / D   = Change character
  ENTER            = Start game

GAMEPLAY:
  W / ↑            = Move up
  A / ←            = Move left
  S / ↓            = Move down
  D / →            = Move right
  ESC              = Back to character select
```
