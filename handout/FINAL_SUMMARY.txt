CHARACTER SELECTION → GAMEPLAY FLOW:
───────────────────────────────────────
  1. GameLauncher created
     └─ Calls ManifestLoader.verifyAssetsExist()
        └─ Prints: "☑ Character available: PUNK"
                   "☑ Character available: BIKER"
                   "☑ Character available: CYBORG"

  2. ScreenManager initialized
     └─ Shows CharacterSelectScreen

  3. User selects "BIKER" with arrow keys

  4. User presses ENTER
     └─ ScreenManager.switchScreen(GAMEPLAY)
        └─ GameplayScreen.loadCharacter("BIKER")
           └─ ManifestLoader.loadCharacterIdle("BIKER")
              └─ Loads: 01_Player_Biker_Idle_...png
              └─ Caches in memory
        └─ GameplayScreen.loadLevel("Industrial_zone_level_1")
           └─ ManifestLoader.loadLevelBackground("...")
              └─ Loads: BG_Composite_...png
              └─ Caches in memory

  5. GameplayScreen.render() called every frame (60 FPS)
     └─ Draws background PNG (from cache)
     └─ Draws character sprite PNG (from cache)
     └─ Updates player position (keyboard input)

  6. User presses WASD or arrow keys
     └─ Character moves on screen

  7. User presses ESC
     └─ ScreenManager.switchScreen(CHARACTER_SELECT)
     └─ Returns to character selection
     └─ Can select different character
